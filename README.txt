MI ENTRENAMIENTO CARDÍACO - APP MÓVIL
1. Sube TODOS estos archivos a la raíz de tu repositorio de GitHub Pages.
2. En Settings > Pages selecciona Deploy from a branch, branch main y carpeta / (root).
3. Abre la dirección de GitHub Pages y añade la app a la pantalla de inicio.
4. Los registros se guardan en localStorage del navegador/dispositivo.
5. Usa "Exportar copia de seguridad" para conservar una copia y poder restaurarla.
